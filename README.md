# NorthLife

> **Privacy-First, Offline-Capable Modular Personal Health & Life Operating System**

Built with pure native web standards (Zero external framework dependencies, IndexedDB local storage, strictly Manrope typography, Tabler SVG icons, and a clinical-grade outcome-oriented UX).

## ✨ Core Features
- **📊 Alive Overview:** High-contrast hero typography, daily summary metrics, and holistic health balance.
- **💧 Hydration Tracker:** Daily intake progress, preset quick log buttons (+200ml, +250ml, +500ml, +750ml), time-stamped timeline, inline edit, and delete with 6-second Undo toast.
- **🥗 Nutrition & Fiber:** Dietary fiber tracking, custom user meal templates (1-click re-logging), real-time search, and edit/undo.
- **🩺 Bowel & Digestive Care:** Clinical Bristol Stool Scale (Types 1–7), pain scale feedback (0–10), straining/blood flags, and digestive history stream.
- **⚡ Habit Routines:** 7-day visual dot matrix, streak counters (`🔥 X days`), and responsive micro-interactions.
- **💊 Medications & Supplements:** Daily dosage schedule, active prescription tracking, and intake log.
- **👨‍⚕️ Doctor Mode:** High-contrast clinical summary table with printable A4 formatting (`@media print`) for physician review.
- **🛡️ Private Local Vault:** Complete offline persistence with IndexedDB and JSON export/backup.

## 🚀 Getting Started
Simply double-click or open `index.html` directly in any modern web browser. No server, bundlers, or build steps required.
